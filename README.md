## React Assignments

Each assignment is a standalone React app with its own dependencies.

- `welcome-components`: functional and class components that receive a `name` prop.
- `composed-layout`: `Header`, `Sidebar`, `Content`, and `Footer` composed by `Layout`.
- `calculator`: addition, subtraction, multiplication, division, and clear.

To run an assignment, open its folder in a terminal and run:

```sh
npm install
npm run dev
```
